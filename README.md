**A unified event intelligence platform built with SvelteKit, PocketBase, and Go.**

InfoSections centralizes events from multiple sources into a single, filterable interface enabling teams and organizations to quickly understand what’s happening, where it matters. This project demonstrates end‑to‑end ownership across frontend architecture, backend design, integrations, and DevOps automation.

---

## Why This Project Matters

- Full‑stack execution across **SvelteKit**, **Go**, **PocketBase**, and modular integrations  
- Product‑minded engineering with clean UX and responsive layouts  
- Systems thinking in event relations, tag management, and integration logic  
- Operational maturity with **GitHub Actions**, **Docker**, and structured initializers  
- Scalable architecture with modular integrations and remote functions  

---

## Core Features

- Unified event dashboard with filtering by **location**, **tags**, and **metadata**  
- Integration‑aware UI that adapts to user‑enabled providers  
- Responsive SvelteKit frontend  
- PocketBase backend with real‑time data and custom Go logic  
- Automated setup and deployment workflows
